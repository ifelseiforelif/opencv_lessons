# 10 прикладів OpenCV-Python

## Встановлення
Рекомендовано Python 3.11 або 3.12 для сумісності з більшістю пакетів.

```bash
python -m pip install opencv-python numpy
```

## Підготовка
Покладіть фотографію `image.jpg` поруч із файлами прикладів або передавайте шлях до фото аргументом:
```bash
python 03_grayscale_and_threshold.py "C:/photos/cat.jpg"
```

Приклади 1–8 приймають шлях до зображення. Приклад 9 сам створює полотно.
Приклад 10 використовує вебкамеру; натисніть Q для виходу.

## Список
1. Читання, показ і збереження.
2. Колірні канали BGR/RGB.
3. Відтінки сірого та чорно-біле зображення.
4. Resize, crop, flip, rotate.
5. Розмиття та зменшення шуму.
6. Межі алгоритмом Canny.
7. Пошук контурів і рамок.
8. Морфологічні операції.
9. Малювання фігур і тексту.
10. Вебкамера та просте виявлення руху.
